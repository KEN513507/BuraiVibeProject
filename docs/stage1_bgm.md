# Stage 1 固定スコア

ゲーム内の **Track 2 / キー 2** が対象。ゲーム開始時にもこの曲を選択します。
Track 1（タイトル）とTrack 9（ゲームオーバー）を含む他9曲は維持しています。

## 構成

`src/stage1_score.h` の `STAGE1_SCORE[128]` が楽譜です。
1行は四分音符1拍、4行で1小節。32小節を512個の16分音符イベントへ展開します。
音階からの乱数選択は行いません。

| 小節 | セクション | 主旋律・Pulse 2 |
| --- | --- | --- |
| 1–8 | A：問いと答え | AマイナーにG♯を組み込み、裏拍の先行発音を次小節へタイ。P2は1つ前の16分音符の音程・発音・休符を追う |
| 9–16 | A′ | 高音域の変奏と4/4内の3＋3＋2アクセント。主にエコー、12小節目はE7アルペジオ |
| 17–24 | B | F・E7・Amを軸に、21小節目でCメジャーへ一時的に開く。P2は同時発音の明記された上3度。最後はAmへ着地 |
| 25–32 | 接続 | エコーとE7アルペジオを交替。下降ベースとタムフィル、最後のG♯→曲頭Aで接続 |

音量係数はP1が0.12。エコーはP2を0.06、Duty 12.5%にし、
Bのハモりは0.084、Duty 25%へ切り替えます。エコー・ハモり・アルペジオは
同じP2を使い、そのうち1つだけを発音します。

`Q(...)` はエコー、`Harmonized(Q(...))` は楽譜に書いたハモり、
`Arpeggiated(Q(...), E4, GS4, B4, D5)` はE7の4音を1フレームずつ巡回します。
和音を同時に4音鳴らす処理ではありません。3＋3＋2は4/4内のアクセントで、
7/8などへの拍子変更は行っていません。

## リズムと音源

- 通常のベースは表拍を休み、裏拍で発音。4小節ごとに固定の下降フレーズを置きます。
- キック／フィルは三角波の4フレームの下降ピッチマクロです。発音中はベースを置き換え、
  終了後にその時点のベース音または休符へ戻ります。三角波の音量エンベロープは使いません。
- Noiseはスネア／ハット専用。ハットは735サンプル、スネアは2205サンプルで停止します。
- NTSCのノイズ周期はハット4 CPUサイクル（レジスタ値00）、スネア380（0A）。
  FamiTrackerの音高表示と実機レジスタの大小関係は逆です。
  [周期と表示の説明](https://forums.nesdev.org/viewtopic.php?t=14355)、
  [三角波の仕様](https://www.nesdev.org/wiki/APU_Triangle)。
- これは既存の4チャンネルソフト音源に演奏技法を追加した実装で、実機ドライバーの再現ではありません。

`H` はタイ（エンベロープを再発音しない）、`R` は休符。
`Q(lead, counter, bass, drum, leadAnd, counterAnd, bassAnd, drumAnd, sixteenth1, sixteenth3)`
で各拍とその裏拍、ノイズ／タムの16分位置を記述します。エコーモードでは
counter欄に代えて、遅延したleadのイベントがP2へコンパイルされます。
`G` は曲を再生成せず、同じ固定スコアを曲頭から再開します。

## 確認

60 FPS想定で16分音符が5フレーム、180 BPM、1周42.667秒です。
ゲーム中のテンポはフレームレートに従います。
`build/stage1_preview.wav` は基準テンポで2周（85.333秒）。
A′は約0:10.667、Bは0:21.333、接続部は0:32、曲頭への帰着は0:42.667です。

MSYS2 UCRT64のツールをPATHへ設定した環境で：

```powershell
cmake -S . -B build -DBUILD_BGM_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
.\build\BgmTests.exe --render-stage1 build/stage1_preview.wav
```

検証／書き出しは音声デバイスや画面を開きません。
タイ・先行発音・エコーの遅延・同時ハモり・マクロのフレーム境界・
キックの排他利用・ノイズ停止・128シードに対する固定性・他9曲のPCM不変性を検証します。
聴感と曲調の評価は試聴で行うため、WAVは確認用の作曲案です。
